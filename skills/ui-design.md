# Skill — UI Design

## Identidade

A identidade visual da Voz da Fé deve ser preservada.

O design system definido no projeto utiliza a paleta:
- `--forest`
- `--gold`
- `--paper`
- `--cream`
- `--ink`

## Princípios

- Interface limpa.
- Inspiradora.
- Elegante.
- Responsiva.
- Consistente.
- Mobile-first.
- Hierarquia visual clara.
- Feedback visual para ações.

## Tailwind

Utilizar Tailwind CSS v4 conforme a arquitetura existente.

Evitar estilos inline repetidos.

Quando um padrão visual se repetir, considerar componente ou token de design.

## Componentes

Manter consistência entre:
- navbar;
- player;
- cards;
- botões;
- formulários;
- modais;
- painel administrativo;
- mini player.

## Player

O estado "NO AR" deve ser visualmente claro.

Play/Pause, volume, mute, qualidade, retry e sleep timer devem possuir estados compreensíveis.

## Responsividade

Nunca projetar somente para desktop.

O portal deve funcionar bem em telas pequenas e em dispositivos touch.

## Não alterar sem pedido

Não mudar:
- paleta;
- tipografia;
- logo;
- identidade;
- estrutura visual principal;

sem solicitação explícita.
